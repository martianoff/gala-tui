# A tour of the mega demo, driven entirely by scripted input — keys AND mouse.
# Columns/rows are 1-based, as a terminal reports them. Coordinates were read
# off recorded frames at 120x36; re-check them if the layout changes.
#
# The tour visits every screen, because a widget the tour never reaches is a
# widget nobody can see working. Each screen is driven with both a click and a
# keystroke where both mean something — the point is not that gala-tui has a
# mouse, it is that the same widget answers to either.
#
# Order matters. A sidebar click navigates, and the sidebar is only rendered on
# the screens that include it: overview, charts, forms, data, review. Builds
# and pipelines give the main pane the whole width, so they are reached through
# the command palette and left with Esc — clicking where the nav *would* be on
# those screens hits nothing at all, which is the hit registry behaving.
#
# Sidebar nav rows, at column 14:
#   6 Overview   7 Builds   8 Pipelines   9 Logs
#  10 Charts    11 Forms   12 Data       13 Review
